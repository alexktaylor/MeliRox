# Meli Rox — Google Ads Search Campaign (build guide)

**Budget:** ~$200 USD/mo (~$6.50/day) · **Optimize for:** WhatsApp leads · **Competitor conquest:** yes
**Launch with 3 core ad groups + 1 competitor group.** Add Corporativos + Eléctrica in Phase 2.

---

## 1. Campaign settings

| Setting | Value |
|---|---|
| Campaign type | **Search** |
| Goal | **Leads** |
| Networks | **Search only** — UNCHECK "Search partners" and "Display Network" |
| Locations | **Medellín + Valle de Aburrá** (add: Medellín, Envigado, Sabaneta, Itagüí, Bello, La Estrella, Rionegro). |
| Location options | **Presence: People in or regularly in your locations** (NOT "interest") |
| Language | **Spanish** |
| Budget | Daily ≈ **COP 26,000** (~$6.50). Google may spend up to 2× on peak days, averages out. |
| Bidding (weeks 1–3) | **Maximize clicks** with a **Max CPC limit ≈ COP 2,000** (~$0.50) — gathers data cheaply, controls cost |
| Bidding (after ~15–30 conversions) | Switch to **Maximize conversions** (add Target CPA later once stable) |
| Ad schedule | All day to start (revisit after 2 weeks; evenings/weekends tend to convert for events) |
| Conversion goal | **generate_lead** set as **Primary** (see §5) |

## 5. Conversion tracking (do this before launch)

1. **Tools → Conversions → New → Import → Google Analytics 4 (Web)** → import **`generate_lead`**.
2. Set it as a **Primary** action (Account default). Everything else = Secondary.
3. Since we optimize for WhatsApp: `generate_lead` already fires on `wa.me` clicks (LeadTracker is live), so we're covered.
4. Add a **Call asset** (+57 304 550 2154) — call clicks also fire generate_lead.

## 7. First 2 weeks — what to do

- **Every 2–3 days:** open **Search terms report** → add junk queries as negatives (this is where budget leaks).
- Watch **cost / conversion** and which **ad group + keyword** drives WhatsApp chats.
- Pause keywords with lots of clicks + zero conversions.
- After ~15–30 conversions → switch bidding to **Maximize conversions**.
- Once it's stable and profitable → add Phase 2 ad groups (Corporativos, Eléctrica) and raise budget.
